### Skills
An important skill I've learned is how to learn. Tinkering with kaboom has been quite difficult, as it was hard to find a good website to run it on that wasnt blocked. I then discovered that I could use the kaboom playground, and was able to practice coding there. 

Another important skill I've learned is debugging. Often times when I am tinkering, I run my code and see a blank white screen. It is frustrating but important to look at your code and make sure everything is working properly. When you find the error, it feels very rewarding.
